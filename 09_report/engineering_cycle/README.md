# Engineering cycle: 5-DOF Micro Arm

Author: Shuayeb Ahmed (branch `shuayeb_ahmed`)

These files take the project through the ten stages of the engineering cycle from CT6056 Lecture 3. Each stage file follows two rules:

1. **Every fact has a source.** Numbered citations `[n]` point to the reference list at the end of each file. If sources disagree, the file says so and does not pick a value silently.
2. **Every process step has a reason.** Each step has a **Why** line that explains the logic: what the step prevents or makes possible, and which later stage or gate depends on it.

The lecture describes the cycle as iterative, not strictly linear: feedback loops and revisions can happen at any stage (Lecture 3, slide 4). The brief's development gates G0 to G7 work the same way, because missing evidence, an unresolved fault or a failed acceptance criterion sends the work back to the current or an earlier gate (brief, Figure 2).
